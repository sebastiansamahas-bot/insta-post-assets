# Inbox

Drop image files (.jpg, .jpeg, .png, .webp) directly into this folder to feed them into the automated posting pipeline.

- No vetting or theme-tagging happens on these — they're used as-is, last in the sourcing priority (after the hand-vetted and Pinterest-verified pools run short for an item).
- Each file is automatically deleted from this folder once the automation uses it — that's how it tracks "already used," so don't worry about cleaning up manually.
- Filenames don't matter, just drop the raw image file.
